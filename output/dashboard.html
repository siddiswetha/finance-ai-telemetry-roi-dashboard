How to read this

  • Cost per run is the tracing view: every run has an id, tokens, cost, latency, feedback, use case, team and user, so any single run can be audited.
  • Usage by use case shows where volume and cost concentrate. Forecasting costs the most per run here because it uses the larger model.
  • Engagement is the share of runs users marked helpful. Low rates (e.g. reporting at 60%) are the signal to investigate, not to hide.
  • ROI is only as good as the time-saving assumption behind it. Treat it as a method demo, not a claim.
